## Highlights

- **MMR no longer throws away most of a large document.** The pre-filter that
  bounds the MMR loop also made every sentence outside the candidate pool
  ineligible for selection, so a document of more than 5000 sentences came back
  capped at the pool — with a 1.2 MB document and a budget of 1,000,000
  characters, MMR returned 115,552 characters where greedy returned 999,998.
  The sentences the pre-filter leaves out are now added back in score order
  until the budget is full. The pre-filter still bounds the MMR loop, so the
  runtime is unchanged.
- **Whitespace between sentences is kept.** A chunk that was only whitespace
  was skipped while splitting, so the selected spans did not add up to the text
  the caller sent — `A.\n \nB.` came back as `A.\nB.`, and leading whitespace
  was lost as well. The whitespace now travels with the span in front of it,
  and the spans concatenate back into the original input.
- **The release workflow cuts from the tag it was given.** A manual run is
  dispatched from a branch, so the tag check compared the tag with the branch
  name and failed the job.
- **Packaging hygiene.** `pyproject.toml` no longer ships in the package, and
  the files that do ship are checked out with LF endings on every platform, so
  a package built on Windows matches the committed source byte for byte.

## Validation

- 35 unit tests, Ruff and the locked dependency audit pass.
- The output contract was attacked with 20,000 random inputs (unit fuzz target
  driven on Windows with a stub `atheris`) with no violation, and the output
  was always an unmodified subsequence of the input.
- `verify_package.py` reports that every packaged file matches the tagged
  source byte for byte, in a clean checkout of this tag.
- The Dify Marketplace validators (`langgenius/dify-marketplace-toolkit`)
  report 0 blocking findings.
- Local Dify 1.20.0 integration: the plugin was installed and upgraded in
  place, then exercised through the plugin daemon's tool dispatch — passthrough,
  greedy, MMR, Markdown, Japanese quotes and boundary truncation all passed.
